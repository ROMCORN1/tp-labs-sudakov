## 1. Чем ветка отличается от копии папки с проектом?
Ветка — это отдельная линия разработки внутри одного репозитория. Она не дублирует файлы физически, а лишь указывает на определённый коммит, поэтому переключение между ветками происходит мгновенно. Копия папки - это полное физическое дублирование всех файлов, что занимает место и быстро рассинхронизируется.
## 2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?
История и все коммиты сохранятся, потому что они хранятся внутри .git, а не в рабочих файлах. Однако рабочая директория окажется пустой — при следующем обращении Git покажет, что все отслеживаемые файлы удалены.
## 3. Зачем нужен Pull Request, если можно коммитить сразу в ​​​​main​​​​?
Pull Request нужен для контроля main: изменения сначала проверяет другой разработчик, и только потом они вливаются в mai.
